## Présentation / Overview

**FR —** Ce projet explore la localisation en deux dimensions d’un téléphone à partir de ses distances à trois stations de base, dont les coordonnées sont connues. Il s’adresse aux personnes qui souhaitent étudier l’estimation de position à partir de mesures bruitées et comparer des variantes de l’algorithme de Levenberg–Marquardt. Il a été réalisé dans le cadre d’un travail sur les méthodes d’optimisation numérique.

**EN —** This project explores two-dimensional phone positioning from distances to three base stations with known coordinates. It is intended for readers interested in estimating position from noisy measurements and studying variants of the Levenberg–Marquardt algorithm. It was created as part of a numerical optimization assignment.

## Fonctionnalités / Features

**FR —**
- Calcule les distances prédites entre une position candidate et les stations.
- Forme les résidus et la jacobienne utilisés par l’optimisation.
- Implémente des mises à jour Gauss–Newton, Levenberg–Marquardt et Levenberg–Marquardt pondérée.
- Produit des graphiques de la trajectoire estimée, des résidus, du coût et du gradient.

**EN —**
- Calculates predicted distances between a candidate position and the stations.
- Computes the residuals and Jacobian used by the optimizer.
- Implements Gauss–Newton, Levenberg–Marquardt, and weighted Levenberg–Marquardt updates.
- Plots the estimated trajectory, residuals, cost, and gradient.

## Problématique et approche / Problem and approach

**FR —** Chaque mesure définit un cercle autour d’une station ; le téléphone devrait se trouver près de leur intersection. Le bruit empêche généralement une intersection exacte. Le script ajuste donc une position en minimisant les écarts entre distances mesurées et distances calculées. Les mesures sont générées par trois fonctions MATLAB compilées fournies (`ping_stolp_1.p` à `ping_stolp_3.p`).

**EN —** Each measurement defines a circle around a station; the phone should lie near their intersection. Noise usually prevents an exact intersection, so the script adjusts a candidate position to minimize the differences between measured and calculated distances. Measurements are generated by three supplied compiled MATLAB functions (`ping_stolp_1.p` to `ping_stolp_3.p`).

## Choix techniques / Technical decisions

**FR —** Le projet est écrit sous forme de script MATLAB avec des fonctions locales pour la géométrie et les mises à jour numériques. Levenberg–Marquardt ajoute un terme d’amortissement à l’approximation de Gauss–Newton pour stabiliser les pas ; la variante pondérée utilise l’inverse des variances estimées par station. Les fichiers `.p` étant compilés, leur implémentation n’est pas modifiable à partir de ce dépôt.

**EN —** The project is a MATLAB script with local functions for geometry and numerical updates. Levenberg–Marquardt adds a damping term to the Gauss–Newton approximation to stabilize update steps; the weighted variant uses the inverse of the estimated per-station variances. Since the `.p` files are compiled, their implementation cannot be modified from this repository.

## Résultats et apprentissages / Results and learnings

**FR —** Le dépôt contient des figures illustrant les cercles de mesure, une trajectoire d’estimation et des courbes d’erreur, de coût et de gradient. Elles témoignent des expériences réalisées, mais ne constituent pas une validation quantitative reproductible. Le script courant indexe les mesures avec `radii(iter)` au lieu de sélectionner les trois mesures de la même itération (`radii(:, iter)`) ; les résidus et les estimations obtenus ne sont donc pas fiables. La priorité est de corriger cette indexation, puis de recalculer et documenter les résultats. Cela met en évidence l’importance de vérifier les dimensions des données et de consigner les paramètres d’expérience.

**EN —** The repository includes plots of the measurement circles, an estimated trajectory, and error, cost, and gradient curves. They document experiments but do not provide reproducible quantitative validation. The current script indexes measurements as `radii(iter)` rather than selecting all three measurements from the same iteration (`radii(:, iter)`), so its residuals and estimates are not reliable. The priority is to correct this indexing, then recompute and document the results. This highlights the importance of checking data dimensions and recording experiment parameters.

## Getting started

### Requirements

- MATLAB R2018b or later (the script uses local functions and `var(..., "all")`).
- The supplied `ping_stolp_1.p`, `ping_stolp_2.p`, and `ping_stolp_3.p` files in the project directory.

### Run

1. Clone or download this repository.
2. Open the project directory in MATLAB.
3. Run the main script:

```matlab
assignment1
```

The script opens figures and prints summary values in the MATLAB command window. No additional package installation or configuration is documented. **The estimates should not be treated as valid results until the measurement-indexing issue described above is fixed.**
